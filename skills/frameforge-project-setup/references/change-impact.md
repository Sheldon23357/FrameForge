# 项目设置变更与制作规格

| 决策 | 权威来源 | 写入工程 | 必须核对 |
| --- | --- | --- | --- |
| 作品名称、作者、简介 | 用户确认的作品信息 | update_project | 简介以玩家可知信息为限，核对改名范围 |
| 播放画幅 | 用户指定的观看或交付场景 | width、height | 画幅与像素尺寸分别核对。现有构图是否依赖画面边缘 |
| 项目画风 | 真人写实或二次元动画与补充方向 | artStyle | 保存前保留仍适用的详细描述。只改描述时沿用当前支持的 preset |
| 生产规格 | 确认的素材、预算与生产方式 | 交接说明 | 标出预览比例、设定参考图比例、单次生成约束分别由谁决定 |
| 开场 | 第一章与其起点 | edit_chapter | 第一章、章内起点和真实试玩路径一致 |

## 换画幅的差异检查

1. 读工程与受影响的画面素材。仅能读取尺寸时，列实际尺寸和疑似适配风险。实际看到画面才判断主体、证据或字幕被裁切。
2. 按影响面追踪已交付的设定图、分镜、视频提示词和已导入片段。设定参考图 3:2 可继续作为身份或空间依据，实际镜头按播放画幅构图。
3. 记录旧值、新值、受影响的交付物和需要补拍或改裁切的片段。项目级设置写入与素材重做是不同的工作，按请求范围执行。

例：横屏切竖屏。站台对峙的两端人物和墙上时刻表各承担一条线索，确认是否能裁切后同时读到。无法同时读到时，交给分镜评估先建立空间再切证据特写，或重构站位。项目设置阶段记录这个缺口，已有素材仍可用于对照。
