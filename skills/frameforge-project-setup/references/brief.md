# 简报与设置映射

| 简报项目 | 工程落点 | 核对 |
| --- | --- | --- |
| 作品名、简介、作者 | `update_project` 对应字段 | 简介可公开给玩家，作者使用用户提供的署名 |
| 播放画幅 | `width` 和 `height` | 常见值 1920×1080、1080×1920、1440×1080、1080×1080 |
| 统一画风 | `artStyle.preset` 与可选的 `artStyle.description` | 预设与补充描述相符 |
| 气氛色调 | `atmosphereTone` | 题材、叙事用色和现有素材相符 |
| 游戏开场 | 第一章的 `startNodeId` | 起点在该章内，试玩进入预期场景 |
| 玩家身份、互动承诺、制作范围 | 制作简报 | 分清用户已确认内容和仍可调整的创作决策 |

已有横屏素材要改成竖屏时，先查真实素材尺寸与涉及节点。用户提供画面时，核对人物是否分居左右、证据是否靠画面边缘、字幕或可读道具是否会被裁切。只有文件信息时说明能确认的尺寸及仍需查看的画面。设定参考图通常使用设定面板的 3:2 画幅，最终镜头取景遵循作品播放画幅。
