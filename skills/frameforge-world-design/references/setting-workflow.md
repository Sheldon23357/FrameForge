# 设定归并、空间图与素材验收

## 角色

从人物称呼、关系、首次出现和后续反证归并身份。确认是同一人时复用设定 ID，同时保留用于查找的别名。面具、身份揭示和季节造型按剧情有效区间记录。只有反复生产且确实需要另一份参考素材的造型才拆条目。

先写行动与辨识锚点，再写造型。角色卡至少要让画面看得出身份，让演员能重复说出相同声线，让后续镜头能稳定复用手、服装、持物特征。声音用音域、共鸣、咬字、语速和情绪变化描述；例如「紧张时刻意放慢，字尾干脆」比只写「沉稳」更可用。

## 场景

画一条文字动线：入口、固定物、关键动作点、出口。每个可复用机位记录观察方向、能见与遮挡、固定光源、环境声以及可通过的路线。室内外同名时用机位关系明确关联。进入另一地点必须经过的门或台阶，在分镜方案中有对应路径。

| 分类 | 内容 | 归属 |
|---|---|---|
| 稳定身份/空间 | 固定脸部特征、常服、门窗、控制台位置 | 工程设定卡 |
| 角色/物件增量 | 左手沾水、持有人改变、图纸被翻开 | 所属路线、节点或分镜交接 |
| 场地事件 | 常态灯光变为红警、短时停电 | 发生点与截止点 |
| 分支私有知识 | 查图后才发现蓝线用途 | 章节与规则，供具体镜头引用 |

## 绑定与复核

查工程资产分类、类型、名称和真实 ID。已有图片匹配不了造型或视角时保留为候选。以设定面板可用资产为准，未核验图像只记录元数据和待挂用途。对同名资产做明确选择。查看工程关联的节点清单，核对设置绑定与本轮场次范围。

返工时沿「设定身份 → 使用节点 → 镜头状态 → 提示词槽位」追踪。换装优先更新对应区间，方位更改回查动作可达和前后景，语音替换回查音色身份、语句和时间窗口。
