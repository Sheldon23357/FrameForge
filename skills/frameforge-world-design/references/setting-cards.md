# 设定卡与参考素材

| 字段 | 角色 | 场景 |
| --- | --- | --- |
| description | 身份、核心目标、处事习惯、关键关系 | 功能、常态、人和制度如何使用这里 |
| visual | 年龄感、五官轮廓、发型、体态、常态服装、可识别特征 | 布局、入口、尺度、可供调度的固定物、材质、光向和配色 |
| sound | 音色、音高、咬字、停顿、语气及其与性格的关系 | 声源、远近、空间反射、稳定底噪与偶发声 |
| imagePrompt | 补定妆图中的造型或视图需求 | 补机位侧、要看见的入口、光照与参考范围 |

新拟或改写的角色形象至少 200 字，角色声音至少 50 字，空白和标点不计。具体辨识特征比同义形容词更有用。交叉核对相似角色的辨识线索。参考图采用设定面板的横向 3:2。分镜里的景别、动作、瞬时表情和道具状态由对应镜头继承；画面引用不足时列出要补的身份图或机位侧场景图。
