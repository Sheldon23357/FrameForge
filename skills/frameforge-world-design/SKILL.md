# 帧叙角色与场景设定

## 工作流

1. 先定位来源与已有设定。用 `read_world_settings` 按名称、类型或节点查找，检查同名、别名和角色的阶段造型。来源冲突时保留用户已确认的版本，标出待定差异。
2. 角色从身份、经历、欲望和典型行为推导形象及声线。稳定特征写入 visual 和 sound。服装、伤势、持物的临时变化跟着章节和镜头记录。需要独立阶段造型时先确认它是否反复使用。
3. 场景从剧情用途推导能被镜头和行动复用的空间。写明出入口、固定锚点、尺度、动线、材料、照明和环境声。道具可在场景或持有者设定中描述，作为可获得资源时另在游戏数据建道具。
4. 按[设定卡与参考素材](references/setting-cards.md)核对字段。用户要求写入时，用 `edit_world_setting` 创建、更新或关联真实节点。已导入的参考图或语音以真实素材 ID 绑定，核对类型。
5. 用户明确要求实际生成时，桌面版可用 `generate_world_reference` 按真实 settingId 生成并绑定定妆图、声音样本或场景参考素材。已有关联时按用户意图决定是否替换。用户明确要求导入时，用 `import_assets` 打开文件选择器，再按返回素材 ID 绑定。宿主没有提供生成工具时使用设定面板入口。提示词请求可在聊天交付，并说明对应设定和素材用途。

## 验收与交接

读回改动，检查身份、外貌、声音和画风互相支持，场景的出入口和锚点能承接实际行动。交给章节与分镜的是设定 ID、角色和场景的稳定事实、已知参考素材及仍需补充的资料。

改编、同人多造型或跨章状态衔接时读[设定来源与状态变化](references/continuity-and-sources.md)。本阶段维护稳定设定和已确认参考素材。局部天气、持物归属与伤污按路线和时间记录在下游交接。修订已经被多个节点引用的设定时，列出会受影响的节点、镜头和素材。

建立完整角色/场景设定、整理多机位或重做场景时，读[设定归并、空间图与素材验收](references/setting-workflow.md)。用文字动线和前后状态交给分镜。
