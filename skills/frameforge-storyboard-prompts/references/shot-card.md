# 分镜卡和冻结帧

每镜记录镜号、章节/节点 ID 或草稿短名、路线、镜头职责、镜长、景别机位、起点、动作和终点、声音、参考图及与下镜接点。只有相关的场景锚点、持物、视线和身体朝向进入每镜。

## 两镜示例

- **站台-01，约 4 秒。** 用全景建立检修门在右、时刻表在左。主角从左侧进画，听见门后钥匙声后停步，右手仍捏着车票。切在目光移向门把手。
- **站台-02，约 3 秒。** 沿同一轴侧切到手和门锁近景。起点是右手捏票停在锁旁，手未碰门。主角用左手试门，门锁微响，右手车票仍可见。

参考图按功能列一遍。身份图用于角色辨识，场景图用于固定地理和光照，首帧用于具体起点。一个槽位缺图时写明需要什么，只有实际提供或确认存在的素材才填真实文件名或 ID。

## 单帧提示词规范

| 字段 | 写法 |
| --- | --- |
| `framing` 取景与构图 | 写景别、视角、方向和高度、裁切位置及对焦对象。焦段有助于控制透视时才写。分镜工具会带入工程画幅或本次指定画幅。 |
| `space` 空间 | 选本机位能看到的空间锚点，写出左右、前中后景、距离和遮挡。特写缩到入画边界，保留能定位现场的一两件物件。 |
| `subject` 主体与状态 | 每个主体交代画面位置、头身朝向、视线、可见手和持物、当场服装及状态。用眼睑、嘴角、肩背、手指等可见细节表达情绪。无人镜写主体物件在这一刻的状态。 |
| `lighting` 光线与质感 | 写光源在哪一侧、落在哪、哪里留暗，以及需要读清的表面质感。沿用工程画风和色调，再写该镜实际可见的照明。 |
| `references` 参考用途 | 按已挂素材的确切名称逐张分工。定妆照可只锁脸和发型，衣服按当场描述；场景参考用同机位侧来锁空间。特写避免套用场景图的全景构图。 |
| `exclusions` 画面限制 | 只写本帧易画错的地方，如多余人物、不应提前出现的证物或需给后期留白的文字区。 |

每帧能独立复制。「同上一镜」、抽象情绪、品质套话、对白、音效和过程性运镜都不能作为画面信息。把「逐渐发现抽屉里的手机」落成某一刻的抽屉开合、遮挡和手机可见程度。首帧与尾帧分别核对对应的起止状态。构图、线索时点和连续性优先，字数随画面复杂度调整。

## 按景别补足可验收的细节

- **证物特写**写明确切入画边界、持物或接触的手、物体方向与遮挡。若证物与背景明度接近，用清晰轮廓、局部反光或焦平面区分，使观众在该帧读出线索。字样本身是证据时，说明观众能读到的内容和承载它的表面，交给后期的字样留出位置。
- **双人对话和反应镜头**分别写身体朝向、视线和相对距离。使用过肩构图时，说明前景是谁的哪侧肩膀、挡住哪里，以及谁的脸或手保持清晰。从已确立的轴线和站位推导画内方位。
- **空间建立镜头**写出后续镜头会用到的出入口、人物位置与固定陈设，用前中后景交代它们的关系。切到近景时只保留该机位看得到的锚点。

## 同场连续性与返工

1. 从节点内容、设定和相邻镜头提取本帧要延续的可见事实。把当场穿着、伤痕在哪侧、道具在哪只手、门是否打开、主光从哪来写成本帧能独立读懂的描述。沿用设定中能辨认的细节，只写当前取景内会拍到的部分。
2. 逐张分配参考图的用途。附图顺序已知时写「图1 · 素材名」，否则用准确名称。角色图对齐身份，本侧场景图对齐固定陈设，定调图按需要对齐光色和材质。若全景参考盖过近景构图，先把近景的裁切和对焦位置写具体；仍偏宽时省掉该参考，在正文保留本帧可见的空间锚点。缺图时把待补项写在制作说明里，等图片就绪再填入提示词的参考用途。
3. 对照成图定位问题，再修改相关字段并重申要延续的画面条件。例如手机与柜底融成一片时，先在光线段给手机边缘一线反光，继续保留原机位、右手握法和抽屉开度。画内文字若需要模型绘制，用引号写出准确文字、所在表面与位置；后期添加的内容保留对应区域。

## 结构化示例

例一是病床视点的无人开场。构图把玩家压在病床视线内，画面只呈现已经能辨认天花板的一刻。

```json
{
  "framing": "仰拍极近景，机位与躺卧者眼睛同高，视线偏向床位右上方。亮灯占上半幅偏右，焦点略软，吊顶接缝仍可辨。",
  "space": "医院病房的方形铝扣板吊顶占满画面，暗灯在亮灯左后方，取景裁在吊顶内，四周不见床沿或墙面。",
  "subject": "两盏长方形顶灯，右边一盏亮，左边一盏熄灭。亮灯的磨砂罩有一圈薄光晕，暗灯罩呈灰白，画内无人。",
  "lighting": "主光来自右上方亮灯，灯罩中心略过曝，周围扣板留青灰暗部。哑光扣板与磨砂灯罩的反光程度分明。",
  "exclusions": "画内仅有吊顶与两盏顶灯。"
}
```
