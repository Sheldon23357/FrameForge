# 从原文覆盖到镜头交付

## 拆分四步

1. **定位范围**。读完整节点内容、关联剧本、相关前后边和设定。把发生的事拆成行动、信息、反应、对白和环境提示。需要核对玩家正文时读取相关页，记录页码和路线范围。
2. **建立空间**。画一行机位关系，列人物、手、物体、固定光和可见区域。先设计同一场的工作侧和方向。需要转轴时用中立机位或看得见的移动建立新方向。
3. **分配职责**。给每个必需事实一个主要镜头。同一事实可跨镜延续，通过覆盖表区分发生和延续。镜数不足可用画外声承载信息，镜头表仍要写出听到什么。用户只要部分页时，将剩余义务标到明确范围外。
4. **定义边界**。用一个静态状态写首帧，再写该镜要发生的变化，最后写终态。连续切点逐项对照双手、持物、人物朝向、接触点、光源与道具状态。停帧图提示词用这一帧可见的状态，运动留给镜头卡和视频正文。

## 可填写的镜头卡

| 字段 | 说明 |
|---|---|
| 镜号与范围 | 稳定镜号、节点真实 ID、故事板页与路线 |
| 叙事职责 | 玩家此时必须看到、听到或理解的事 |
| 空间 | 景别、机位侧、视线、前后景、关键物体 |
| 起止 | 姿态、双手接触、道具、光和画面位置 |
| 过程 | 主体动作、摄影机运动、关键音画点及秒数 |
| 参考 | 已确认身份/版本、用途、待挂项 |
| 交接 | 下一镜接点、独立尾帧需求、覆盖剩余项 |

## 如何验收修订

移动镜头先核对前后切点，拆并镜要写旧镜号与替代镜号映射。返工时先审覆盖再审美感。原来由画外广播承担的信息，如果改成静音，必须先把它移到有声镜头或把变更反馈给章节。用户要求保留故事义务时，镜数受限的解决方式应能在成稿中看到。最终报告所改镜号、改动前后、受影响的视频提示词和素材。
