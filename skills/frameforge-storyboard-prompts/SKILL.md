# 帧叙分镜与图像提示词

从工程设置读取 `atmosphereTone`。生成设定图或分镜图时，工具会自动附加色调。只在对话交付提示词时，把该段色调加入可复制正文一次。

## 读取输入

从头规划或重做整个帧叙节点时，先用 `read_skill` 打开 `frameforge-node-storyboard`，把整组景别、镜长和切点排定，再沿用其镜头表写静帧。

用用户指明的节点或发送时选中的节点。回读节点内容（`read_story.read` 的 `section=notes`）、所属章节、实际前后节点、入镜设定和用户指定素材。节点内容缺漏时按需查所属章剧本和现有玩家文字。用 `read_story.shots` 按真实 nodeId 查已有镜号，再用 `read_story.shot` 按真实 shotId 查镜头内容。先找当前节点实际可见的前后接缝；分支的互斥动作各写各的镜头。只有文件元数据时，将具体画面标为待核对。

若节点有 `choiceQuestion`，它由游戏界面随选项显示。分镜保留形成选择的情境和已确认的剧情对白，画面提示词无需复述界面问题。

## 拆镜与提示词

静帧提示词正文默认用中文。只有用户明确指定其他语言时才切换。参考素材 ID 和模型需要的标签沿用原格式。

新写或重写的静帧提示词用 `framing`、`space`、`subject`、`lighting` 四个必填字段，按需加 `references`、`exclusions`。使用[分镜卡和冻结帧](references/shot-card.md)中的字段规范和示例。把对象直接写入 `edit_production_shot` 的 `firstFramePrompt` 或 `lastFramePrompt`，工具会依序排成可复制的带标题正文。已有提示词只有一句梗概、混入动作过程或提前揭露线索时，先按当前镜头和节点内容重写，再出图。用户明确指定沿用原文时可直接使用现有文字。

同场有临时服装时，每张能看见衣服的提示词都写清这一镜实际穿着。离身的外套可写其落点，例如搭在陪护椅背。定妆参考有外套而本场已脱时，指定它只参考脸和发型，同时写清本场当前只穿哪一层。看过且衣服正确的同场图可补作服装参考。

1. 给每镜定一个职责：揭示信息、改变行动、建立空间、给反应或转场。按戏剧动作而非固定镜头数拆分，用户指定数量时在该预算内安排。
   输出前注明覆盖的场次或节拍范围，逐项核对该范围内改变玩家认知的声音、对白和动作。镜数有限时可用画外声承载关键事实，剩余情节明确标成后续镜头。
2. 同场多镜先记录空间锚点、轴线、机位工作侧、人物相对位置和动作交接。为每镜保留稳定镜号，明确景别、画幅、机位、动作起止、对白或声音、时长依据与下一镜接点。
3. 估时依据是实际发声窗口、动作先后和停顿。关键信息需要足够的可读时间。镜长预算不够时先调整覆盖关系或拆镜。
4. 冻结帧提示词只写同一瞬间可见的事实，光线和动作写成静态结果，推拉摇移和动作过程写在镜头表。首帧写动作发生前，尾帧只在确有交付需求时写动作结束后。分别列已确认参考图与待准备的参考槽位。
5. 交付分镜表和逐镜可复制的图像提示词。写入工程时，用 `edit_production_shot` 保存镜号、剧情节拍、镜长、机位、起止状态及对应帧提示词，更新同一镜头用真实 shotId 和 patch。已保存时直接调用 `generate_shot_image`，省略 `prompt`，使详情中看到的正文与出图使用的正文一致。临时完整改稿可传 `prompt` 对象。工程的 `storyboardPages` 保存玩家剧情文字。生成图片绑定镜头卡，按请求用 `edit_timeline.append_shot_frame` 加入图片轨。

多镜场面、镜数压缩、拆并镜或轴线问题时，读[覆盖、调度与修订](references/coverage-and-revision.md)。

交付多镜分镜和关键帧时，读[从原文覆盖到镜头交付](references/storyboard-workflow.md)。按覆盖表、镜头卡和冻结帧验收。

## 阶段契约

分镜拥有镜头职责、起止状态、镜长、机位和冻结帧，继承剧情事实、对白和画风。拆并镜需记录旧镜号、替代镜号与覆盖去向。下游可提出修订，已经确认的镜长、对白与边界需要显式对齐。写完分镜后用镜号和节点标记影响范围。

## 验收与交接

出图前做一次画面核对。读者应能指出第一眼看到什么、画面裁在哪里、哪些线索可见或被遮住，以及参考图各控制什么。按景别补齐必要细节，具体判据见[分镜卡和冻结帧](references/shot-card.md)。

逐项比对相邻镜头的头身朝向、视线、双手、持物和光照。直接连续的镜头把接缝动作归入其中一镜，允许剪辑省略时明确写成切点，避免同一动作在起点说明和首帧提示词出现不同版本。交给视频提示词的是镜号、时长、起止画面、动作、运镜、对白和参考图映射。
