# 章节情节剧本交接

每场使用「## 场次 1-01 场名」。场号在本章唯一。章节剧本是作者正文。蓝图与制作阶段按所属章节、节点内容和实际前后节点定位情节。

| 记录 | 下游需要读到的内容 |
| --- | --- |
| 时间、地点与入口 | 从哪一场或哪条选择过来，主角知道什么、手里有什么，任务处于哪一阶段 |
| 发生的事 | 主角行动，对方反应，造成的新局面，哪条线索在何处传给玩家；用概述交代说话意图 |
| 选择与分支 | 玩家已有依据、每项可执行行动和门槛、即时后果场次、长线读写或任务变化 |
| 离场与汇流 | 下一场编号、适用于所有入口的共同事实、分支保留状态 |
| 跨章交接 | 本章结果、下一章入口、需要继续追踪的线索或结算 |

两路都进入控制室时，共享场次只引用两路都见过的停电和警报。值班表路线保留「能证明伪造时间」，备用渠路线保留「可从备用阀绕行」。后续可在具体选择读取这些状态。把一次选择与其产生的两种场戏都写出来，留出足够信息让蓝图阶段决定是否把各后果场拆成多个节点。
