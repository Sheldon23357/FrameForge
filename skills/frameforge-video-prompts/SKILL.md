# 帧叙视频提示词

## 输入与生成方式

从头规划或重做整个帧叙节点时，先用 `read_skill` 打开 `frameforge-node-storyboard`，沿用排定的景别、节奏和动作接缝，为选定的连续片段写跨帧视频提示词。

以节点内容、所属章的对应情节和制作镜头卡为依据。继承分镜中的镜号、时长、动作起止、台词、画幅和视听连续性。用户同时要求拆镜和视频提示词时，先用分镜技能确立这些输入，再按连续时间写运动。已有分镜不完整时，只补本次提示词依赖的起点、终点和时序，标明推定内容。

优先用 `read_story.shots` 按真实节点 ID 查镜号，再用 `read_story.shot` 按 shotId 分别读取 details 和 prompts。把视频提示词作为跨帧的连续动作方案交付到对话。已有视频素材可用 `edit_production_shot` 的 update 绑定其 ID。已入库视频需要实际播放时再用 `edit_timeline` 编排。只有用户要求创建新镜头时才新建镜头卡。

用户未指定本次画幅、分镜也未标注时，先用 `read_project` 核对工程画面宽高。按宽高换算播放画幅并用于逐镜正文，例如 1920×1080 是横幅 16:9。缺可核查的尺寸时将画幅标为待定。

从工程设置读取 `atmosphereTone`。根据片段内的连续时间编写视频提示词，使用镜头卡作为参考。直接在对话交付新提示词时，将项目色调加到可复制正文中一次。

按节点正文页编排镜头时，分别记录工程中的文字停留时长和本次镜长。两者的数值有差异时写明来源和同步需求，按本次明确指定的镜长交付。

- **有确认的首帧**：用图生视频，重点写帧内运动、必须锁定的持物/接触和终点。
- **计划挂图**：列待挂首帧、角色图或地点图与各自用途，按图生视频的目标写正文。
- **用户要求文生视频**：补全人物、空间、构图和光线的静态锚点。
- **指定模型**：使用有依据的参考编号、声轨能力和镜长约束。资料未提供或能力未确认时，交付通用可复制版并标出待核对参数。不要根据当前对话模型猜视频生成模型。

节点的 `choiceQuestion` 由播放器随选项呈现。逐镜正文保留剧情动作、线索和节点制作阶段已细化的对白，界面问题由播放器呈现。

## 逐镜成稿

视频提示词正文默认用中文。用户明确指定其他语言时按本次要求执行。原台词和目标模型需要的素材标签保持原格式。

1. 用「起点 → 触发 → 有序动作 → 终点」写出方向、接触对象、反应和结果。描述镜头固定或如何移动、何时停稳。
2. 写出对白、旁白或环境声的起点和可用发声时间。沿用节点分镜已确定的台词和说话人，避免运动与发声同时争用动作。把改变剧情理解的画外声和对白放进可复制正文，显式时间段覆盖镜长。
3. 图生视频正文重述足以锁定动作的局部信息。参考槽位单列一次，只挂用户指定的参考或经确认的相关设定图。看到文件名不等于看过画面；未指定的旧视频与音轨不自动作为参考。
4. 每镜交付镜号、镜长、参考槽位与一段可复制的模型正文。发现接缝冲突时，明确采用哪个切点。可在既定镜长和分镜边界内处理的，把动作实际写入秒段、同步修正待挂首帧描述。若需改动已确认的分镜边界，保留原边界并标明该镜待修，附具体调整建议。发布前比对制作备注与正文，确保两处描述的是同一个处理方案。

读[时序与模型交付](references/motion-delivery.md)处理显式时间段、首尾状态及模型参数核对。提示词按用户要求交付到制作镜头卡。玩家剧情文字保留角色内心、当前声画尚未明确的事实和选择前线索。

指定模型、多个参考槽位、连续生成或多镜组合时，读[执行端规格与投产判断](references/execution-profile.md)。本阶段负责可复制的运动正文和模型交付规格，继承分镜的镜号、镜长、对白和起止。验收时逐段做时间算术，对照接缝、素材、台词与正文，分别标出可复制程度和执行前缺口。

连续多镜、精确声画编排或制作返工时，读[视频投产、退回与重试](references/production-revision.md)。用正文时间戳复算并核对已确认的镜头与声音义务。
