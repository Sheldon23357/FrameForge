# 时序与模型交付

## 可复制提示词示例

**站台-02，3 秒，图生视频。** 参考槽位：首帧是站台-02 已确认关键帧；车站图用于锁孔与门板位置。

> 固定近景，保持门锁在画面右侧。0–0.5 秒，右手捏住折角车票，停在锁旁。0.5–1.7 秒，左手伸向把手，向下压到阻力点，门锁发出短促金属响。1.7–3 秒，左手松开把手退离画面，右手仍捏住车票停在原位，门始终关闭。背景持续低弱风声，无对白。

此例三个时段覆盖 3 秒。持物、门的状态和手的去向是下一镜能继承的具体事实。

检查每个秒段内部的动作和发声预算。例如 0.6–2.2 秒只有 1.6 秒，不能在其中安排 2 秒白噪后再报站。可以缩短白噪、明确让报站叠在白噪上，或从相邻段重新分配时间。检查提示词正文和制作备注中的数字是否一致。

## 模型能力核对

| 需要确认 | 如何影响交付 |
| --- | --- |
| 原生时长或离散时长选项 | 以已确认分镜时长为基准。若执行端超限，标出如何拆分、接续或后期剪辑 |
| 首帧、尾帧、多参考图各自支持范围 | 给每张图明确职责。模型只支持首帧时，把终点作为文字约束 |
| 声音、口型与外接配音 | 有原生声轨时写说话人和时段。外配时明确音轨制作与对齐点 |
| 单段和多段的镜头边界 | 每次切镜点必须来自分镜；按段检查首尾帧、画轴、持物和动作 |

将制作备注、模型参数和可复制提示词分开。复核首帧可观察事实、帧内状态变化、镜长内能完成的动作、结尾停留和下镜接缝。
